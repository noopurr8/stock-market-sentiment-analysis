📈 Stock Market Sentiment Analysis & Price Movement Correlation

 Overview
This project analyses the relationship between market sentiment and NIFTY 50 price movements using historical stock market data and machine learning techniques.

Features
- Historical NIFTY 50 data analysis
- Sentiment score integration
- Data preprocessing and feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Linear Regression
- Logistic Regression
- Random Forest Classification

Tech Stack
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | yfinance

 Results
The project demonstrates how market sentiment can support stock market analysis by identifying correlations between sentiment scores and NIFTY 50 price movements.
